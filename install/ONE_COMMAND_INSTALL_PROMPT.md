# One Command Install Prompt

Use this prompt in a new project:

```
Install Agent Workflow from Ran-sh/chatgpt_workflow.

Read the workflow protocol first.
Analyze this repository structure.
Generate project-specific Agent Workflow files.
Do not modify business source code.
Do not create implementation tasks.
Only install workflow infrastructure.

Report:
- installed files
- detected stack
- generated configuration
- next steps
```

The installation should create a project-local copy. Projects should not depend on the template repository at runtime.
