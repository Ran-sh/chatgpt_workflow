# Codex Adapter

Codex is an execution platform.

It may execute any approved ACTIVE task mode:

- IMPLEMENT
- TEST_ONLY
- REVIEW_ONLY

Codex must:

1. Read the permanent workflow protocol.
2. Read only its assigned ACTIVE task.
3. Follow the task contract.
4. Return evidence and result report.

Codex is not assigned a fixed responsibility by platform identity.
